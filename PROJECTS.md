# Project index

This catalog lists every project in the roadmap. Each project has a **starter**, **core**, and **stretch** deliverable, defined in the linked section. You are not expected to complete all **80** projects.

**Intended path:** the 9 shared projects (S01–S09) + one pathway (12 or 18 projects) + that pathway’s capstone (C1–C5). That is **22** or **28** projects.
